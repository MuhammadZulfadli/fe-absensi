# FE Absensi

Proyek Frontend untuk aplikasi absensi mahasiswa.

## Teknologi

- Vue 3
- Vite
- Vue Router
- Axios

## Setup

1. Clone repositori
2. Copy `.env.example` menjadi `.env`
3. Sesuaikan `VITE_API_URL` di dalam file `.env`
4. Jalankan `npm install`
5. Jalankan `npm run dev` untuk development server

## Skrip

- `npm run dev`: Menjalankan server development
- `npm run build`: Membangun aplikasi untuk production
- `npm run preview`: Pratinjau build production secara lokal
